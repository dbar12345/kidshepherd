Getting started

  1. Install Kid Shepherd on the parent's iPhone and the child's iPhone.
  2. Parent: open it → This is a parent's iPhone → +. A QR code and a 6-digit code appear.
  3. Child: open it → This is my kid's iPhone → Scan the QR code (or type the code).
  4. Check that the safety number is the same on both phones.
  5. On the parent's phone, follow Set up [child]: protection mode, Parent Zone PIN, app groups, always-allowed apps, rules.

Common questions

Do I need Family Sharing? No. Screen Time: child in Family Sharing is the strongest mode. Any iPhone works for teens and adults. Reminders only works without Screen Time but doesn't block apps.

Why are app groups picked on the child's phone? Apple only lets apps be chosen on the device they're installed on. Everything else is set from the parent's phone.

A change didn't reach the child's phone.

  • Both phones need internet and to be signed in to iCloud.
  • If Kid Shepherd was swiped away on the child's phone, the change applies when it's opened.
  • Update both phones to the same version.

A schedule didn't block.

  • Check the schedule's Blocks: All apps / Only … setting.
  • Extra time given during a schedule ends it early.
  • Look at Manage › Device & diagnostics › Diagnostics log.

Location or place alerts don't work. On the child's phone: Settings › Privacy & Security › Location Services on → Kid Shepherd › Always.

Start over or switch roles. Parent: Family › About this device › Reset this device. Child: Parent zone (PIN) › Reset this device.

Privacy

Kid Shepherd has no accounts, ads or tracking. Family data is end-to-end encrypted between your family's devices. Privacy policy: privacy.html
